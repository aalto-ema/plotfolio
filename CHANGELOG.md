# Changelog

## Unreleased

- Added atomic autosave snapshots and explicit restore/discard recovery for interrupted sessions.

- Added final-size publication checks for clipping, small text, unavailable fonts, image resolution and overlaps.

- Added direct editing from plotted labels, curves, legends and annotations; double-click fitted curves to style them.

- Added fitted-curve styling for new and existing fits, with live previews, band colors/opacity and undoable edits that preserve numerical results.

## 0.4.0 — 2026-10-13

- Added multi-file CSV/TSV/Excel import with delimiter/header previews and column roles/units.
- Added source-free reusable figure templates, column mapping and background batch exports with file/folder inputs and overwrite preflight.
- Added linear, polynomial, exponential and safe custom fitting, parameter bounds, weighted least squares, residuals, covariance diagnostics and approximate confidence bands.
- Added immutable derived tables with recorded operations, provenance review and recomputation.
- Added explicit replicate summaries, raw-point overlays, asymmetric errors and uncertainty bands.
- Added data-driven zoom insets with connectors and linked unit axes, accessed through modal panel tools.
- Organized advanced workflows in Analyze, Templates and Panel tools menus.


- Added inside/outside/shared legends, independent font sizing, columns and advanced spacing/frame controls, plus draggable positions and reset.

- Added per-panel X/Y position offsets in millimetres and an undoable position reset.

- Added direct numeric figure dimensions, editable panel gaps, and an undoable size/spacing reset.

## 0.3.0

- Renamed to PlotFolio and split the application into an installable src package.
- Added MIT licensing, contributor documentation and CI.
- Added Arial defaults, balanced title-free CV/Nyquist/bar/heatmap examples.
- Added panel-label formatting and global/per-panel positions.
- Added exact-size vector manuscript PDF preview and existing-PDF placement.
- Unified inspector backgrounds and refined form, combo and scrollbar styling.
